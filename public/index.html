Questions, answered honestly.

Does it read my screen or record keystrokes?

No. Guardian reads structured metadata only — active app, window title, and (via the optional extension) the current tab's domain and title. No screenshots, no keystroke logging, no password capture, ever.

Will it block me the moment I open a distracting site?

No. It takes multiple sustained signals before anything happens, and the default never goes past a check-in dialog. Temporary blocking only exists in Strict mode, which you opt into per session.

Do I need an OpenAI/Anthropic API key?

No. A deterministic rule engine handles the obvious cases with zero network calls. An AI model is only used, optionally, for genuinely ambiguous activity — bring your own OpenRouter key if you want that.

Where does my data go?

Nowhere, by default — everything lives in a local SQLite file you can delete at any time. n8n sync and AI classification are both opt-in and off unless you configure them.
